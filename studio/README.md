# Модуль — редактор мебели для менеджера

Актуальная ночная итерация: [ITERATION-03.md](docs/ITERATION-03.md). Производственные источники и ограничения: [WORKSHOP-RULES.md](docs/WORKSHOP-RULES.md). Сервер: [SERVER-CABINET.md](docs/SERVER-CABINET.md).

## Запуск

START-3D.bat в корне проекта запускает редактор http://127.0.0.1:8103/studio/ и локальный API кабинета на8104. Нужен Node.js и Python с зависимостями server/.studio-deps. STUDIO_PYTHON задаёт путь Python, если встроенный путь Codex отсутствует. Для внешнего размещения нужны настройки из SERVER-CABINET.md; сейчас используется явный локальный демо-режим без отправки писем.

## Возможности

- До40 отдельных корпусов шириной250–900, высотой400–2200 и глубиной250–700мм; ЛДСП16. Повороты90°, установка сверху, копирование и поиск свободного места.
- Перетаскивание корпусов с привязками, наполнения по высоте и между секциями. Размеры на модели редактируются нажатием. Прозрачность, открывание фасадов, разнесённый вид.
- Полки, ящики с дномЛДСП16 и обязательной полкой сверху, фальши для открывания; шариковыеGTV и скрытыеGTV0FPO, штанги с фланцами, пантограф.
- ЗадняястенкаЛХДФ набивная/впаз, ЛДСП вкладная или безстенки. Крепление новых вариантов требует технологической проверки.
- Прямоугольная комната с окнами/дверями, интерактивный план, карточка замера.
- Смета из листов/материалов/части фурнитуры, ввод недостающих цен; предварительные карты листов, CSV, ведомость, проверочные бирки и КП.
- Показ клиенту и PNG до2560px. Скачивание подтверждено в Edge; во встроенном браузере может не работать.
- JSON версии3, миграция старых студийных файлов, отмена/повтор, локальная библиотека шаблонов. Кабинет менеджера/администратора с разграничением доступа и историей версий; сохранение на сервер вручную.

## Границы

Это ещё не полная замена Базиса. Нет проверенной присадки/УП, произвольных контуров помещения, сложных угловых корпусов, полной библиотеки механизмов и автоматического выпуска производства. Карты — эвристическое размещение с фиксированной текстурой, полем10мм и промежутком10мм; не гарантируют минимального числа листов. Кромление и крепёж требуют технологической приёмки. Смета предварительная, без полного крепежа/доставки/монтажа. Облачный сервер не развёрнут. Печатная пагинация бирок ещё не проверена.

## Разработка и проверки

В studio: npm ci, npm run build, npm test. Готовая сборка web/studio. Проверки интерфейса проводятся в браузере на8103. Серверные тесты: Python server/test_studio.py. Старый2Dредактор и его база не изменяются новой серверной частью.

Ручной маршрут встроен в «Как пользоваться»: замер → корпуса → наполнение → документы → показ клиенту → кабинет. Начните с изменения размера на модели, перетаскивания полки и добавления корпуса; затем проверьте смету и карты, сохраните проект в кабинете и откройте его историю.
