# Модуль — редактор мебели для менеджера

Актуальная ночная итерация: [ITERATION-03.md](docs/ITERATION-03.md). Производственные источники и ограничения: [WORKSHOP-RULES.md](docs/WORKSHOP-RULES.md). Сервер: [SERVER-CABINET.md](docs/SERVER-CABINET.md).

## Запуск

START-3D.bat в корне проекта запускает редактор http://127.0.0.1:8112/studio/ и локальный API кабинета на8104. Нужен Node.js и Python с зависимостями server/.studio-deps. STUDIO_PYTHON задаёт путь Python, если встроенный путь Codex отсутствует. Для внешнего размещения нужны настройки из SERVER-CABINET.md; сейчас используется явный локальный демо-режим без отправки писем.

## Возможности

- До40 отдельных корпусов шириной250–900, высотой400–2200 и глубиной250–700мм; ЛДСП16. Повороты90° вокруг центра с подстройкой у стен, установка сверху, копирование и поиск свободного места. Антресоль наследует материалы/задник и оставляет 30мм под потолком по СТП.
- Перетаскивание корпусов с привязками и их отключением, наполнения по высоте и между секциями. Перегородки двигаются по ширине, пересчитывая соседние секции. Размеры на модели редактируются нажатием. Прозрачность, открывание фасадов, выдвижение выбранного ящика для просмотра, разнесённый вид. Зеркальное отражение секций; числовая ширина, разделение и удаление сохраняют прочие проёмы.
- Полки, ящики с дномЛДСП16 и обязательной полкой сверху, фальши для открывания; шариковыеGTV и скрытыеGTV0FPO, штанги с фланцами, пантограф. Применение направляющей всем ящикам секции; высоты и положения сохраняются. Распределение полок по равным проёмам в свету.
- ЗадняястенкаЛХДФ набивная/впаз, ЛДСП вкладная или безстенки. Крепление новых вариантов требует технологической проверки.
- Прямоугольная комната с окнами/дверями, объектами замера (колонны/балки/радиаторы с проверкой пересечений), интерактивный план, карточка замера и расчёт вычетов для ниши по СТП. Подсказки о корпусах у проёмов и недостаточном зазоре до потолка. Отступы от стен учитывают поворот и выступы габарита расстановки.
- Смета из листов/материалов/части фурнитуры, ввод недостающих цен; предварительные карты листов, CSV, ведомость, проверочные бирки и КП. Просмотр ведомости внутри редактора, включая монтажные замечания. Поиск детали на листе; размерные виды корпусов и таблицы высот наполнения для согласования.
- Показ клиенту и PNG до2560px. Скачивание подтверждено в Edge; во встроенном браузере может не работать.
- JSON версии3, миграция старых студийных файлов, отмена/повтор, локальная библиотека шаблонов с переносом JSON и отменой удаления. Поиск проектов кабинета по названию/сотруднику и сортировка. Кабинет менеджера/администратора с разграничением доступа и историей версий; сохранение на сервер вручную. Сверка несохранённых изменений с сервером, резервная копия перед открытием другого проекта; защита от запоздавшего ответа после закрытия кабинета. Скрипт согласованного резервного копирования серверной SQLite и опциональная раздача студии единым Python-сервером описаны в SERVER-CABINET.md. Массовая смена декора по выбранному назначению доступна в каталоге.

## Последние улучшения

- Общий габарит закрытой композиции включает ручки; выход ручек за стены отмечается подсказкой.
- В замере можно сдвинуть все корпуса общими отступами. На плане доступны стрелки10мм/Shift100мм, выбор конкретного проёма с переходом к карточке.
- Выбранный ящик подсвечивается в3D, вкладки показывают его положение. Команды всего блока свёрнуты отдельно; компактная сборка сохраняет физический порядок и фурнитуру.
- Документ «Расстановка»: план, таблицы корпусов/проёмов, замер и предупреждения, встроенный предпросмотр.
- Повреждённая локальная библиотека сообщает о проблеме и сохраняет исходную запись перед явным восстановлением.

## Границы

Это ещё не полная замена Базиса. Нет проверенной присадки/УП, произвольных контуров помещения, сложных угловых корпусов, полной библиотеки механизмов и автоматического выпуска производства. Карты — эвристическое размещение с фиксированной текстурой, полем10мм и промежутком10мм; не гарантируют минимального числа листов. Кромление и крепёж требуют технологической приёмки. Смета предварительная, без полного крепежа/доставки/монтажа. Облачный сервер не развёрнут. Печатная пагинация плана, ведомости, бирок и размерных видов ещё не проверена.

## Разработка и проверки

В studio: npm ci, npm run build, npm test. Готовая сборка web/studio. Проверки интерфейса проводятся в браузере на8112. Серверные тесты: Python server/test_studio.py. Старый2Dредактор и его база не изменяются новой серверной частью.

Ручной маршрут встроен в «Как пользоваться»: замер → корпуса → наполнение → документы → показ клиенту → кабинет. Начните с изменения размера на модели, перетаскивания полки и добавления корпуса; затем проверьте смету и карты, сохраните проект в кабинете и откройте его историю.

Последние проверки ночной версии 06.09.2026 — 112 теста модели/проектов/раскроя и 10 серверных тестов прошли; последняя сборка успешна. Это проверка реализации, не технологическая приёмка производства.

Дополнения: групповой перенос всей композиции в3D/на плане/по отступам; копирование выбранной полки и ящика с настройками; высота выбранной полки в её карточке; защита повреждённого стартового проекта и запоздавшего импорта файла.

Документы можно скачать единым ZIP-комплектом для технолога: исходный проект и восемь сопроводительных файлов из одного состояния. В комплект входят внутренняя смета и памятка о проверке; отправка клиенту выполняется отдельным КП.

Печать проверена в Chrome PDF на комплекте из 3 корпусов: 3 страницы размерных видов, 6 карт, 2 ведомости, 2 плана, 7 страниц бирок (66 шт. по 90×50 мм). Физический принтер и произвольные большие проекты отдельно не проверены.

«Двигать группу» позволяет совместно переносить отмеченные корпуса в 3D, на плане и через отступы. Остальные остаются на месте; выбор группы временный.
