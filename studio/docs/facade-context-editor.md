# Редактор фасадов из ПКМ и выделенная группа

15.10.2026. Ветка codex/facade-context-editor.

ПКМ по двери или фасаду ящика → «Редактировать фасад». Окно использует существующий каталог Вернисаж (плёнка, матовая/глянцевая эмаль, фрезеровки, толщины, ограничения и цены); рамки и ЛДСП также доступны. Черновик не меняет проект до применения; закрытие/Отмена отбрасывает выбор.

Shift+клик в сцене, на плане или в списке включает/выключает корпус в группе (решение Макса 30.10; до 30.10 — Ctrl+клик, теперь Ctrl — привязка к пересечению); Shift+перетаскивание двигает группу вместе. Зелёная рамка и подпись показывают группу. «Фасады выделенных (N)» открывает редактор сразу с областью «Выделенные модули». Можно выбрать корпус или все редактируемые модули. Снять выделение — отдельной кнопкой. Оформление затрагивает все фасады внутри выбранного корпуса; индивидуальное покрытие одной створки не реализовано.

Применение одной групповой командой, undo/redo и сохранение — через общий commitProject. Размеры, наполнение, открывание, количество дверей не копируются. Корпуса без фасадов, импорт Базиса, купе, столешницы и столы пропускаются; цены и конструктивные правила не изменены. Неподходящие по паспорту фасады блокируют всю операцию, частичного изменения нет.

Проверка: facade-appearance.test.ts (цены, сериализация, исходник не изменён, выбранные адресаты, атомарность); два сценария в room-workspace.spec.ts (реальный ПКМ, плёнка/краска, отмена черновика, Ctrl группы в списке/плане/3D, Ctrl+Z/повтор/перезагрузка). Дополнительно вручную через браузер выбрана и изменена группа двух корпусов. Логи .qa/facade-editor/ не публикуются.
