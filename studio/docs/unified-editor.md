# Единое построение мебели — 14.10.2026

Решение Макса: начальный шаг «Помещение» содержит габариты, проёмы и коммуникации. Следующий шаг «Построение мебели» объединяет расстановку, наполнение и фасады. Последний шаг — «Документы».

## Поведение
- Модули добавляются слева, параметры выбранного модуля и секции — справа. Тематические разделы изначально закрыты. При выборе отдельной детали открывается соответствующий раздел. Порядок элементов клавиатурой совпадает с порядком на экране.
- «Фасад → Применить ко всем модулям» переносит тип/материал фасадов, сохраняя габариты и индивидуальные ручки. Импортированные модели Базиса, столешницы, столы, двери купе и техника без мебельного фасада исключены. Ошибка любого получателя отменяет всю операцию. Изменение возвращается одним Ctrl+Z.
- ПКМ по двери, её петле или ручке → «Открывание → Петли слева / Петли справа» перевешивает только эту дверь. Геометрия петель и положение ручки следуют выбранной стороне. Действуют отмена, повтор и сохранение.
- Прямая кухня принимает длину ряда, высоту нижних модулей с опорами и глубину нижних корпусов. Столешница и навесные получают соответствующие высоты. Проверка места учитывает окончательное положение с боковыми фальшами, поэтому ряд не принимается частично и не создаёт собственных пересечений после добавления.
- Старые идентификаторы шагов доступны контекстным командам, но не образуют дополнительные вкладки. Ключи хранения и проекты сохранены. При открытии редактора показывается «Помещение».
- Перетягивание границ боковых панелей, пустой проект, удаление последнего модуля, общая история действий и увеличение фасада ящика с подъёмом верхних ящиков включены через Git из прежней ветки.
