### Подготовка размещения: единый сервер
Готовых конфигураций внешнего деплоя в репозитории не обнаружено. В сервер добавлена опциональная раздача собранной студии и текстур через STUDIO_SERVE_WEB=1. UI и API могут работать на одном loopback-порту за HTTPS reverse proxy; Node не нужен при обслуживании готовой сборки. По HTTP разрешены только studio и assets/tex; тест проверяет недоступность остальных файлов, работу API и отказ при отсутствии сборки. Все 7 серверных тестов проходят на временных БД. Внешний деплой и проверка реального HTTPS/SMTP не выполнены; текущий локальный сервер не перезапускался, прежний запуск 8103/8104 сохранён.

### Резервное копирование кабинета
Добавлена backup_studio.py: согласованная копия через SQLite backup API из работающей базы, уникальное имя без перезаписи, quick_check и счётчики проектов/версий, закрытие соединений при ошибках. Каталог studio-backups исключён из Git. Тест с открытым WAL-соединением проверяет сохранность двух версий и независимые повторные копии; все 8 серверных тестов проходят.
