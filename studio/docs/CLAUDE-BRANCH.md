## Шаг 1 · 06.09.2026 — смета считается для любого декора и обеих систем направляющих

Причина: у Codex цена листа была задана для 15 декоров из 133, у скрытых направляющих цены не было,
поэтому для большинства реальных заказов смета отвечала «недоступна». Ядро модели и геометрия не тронуты.

- `scripts/catalog.cjs`, `src/catalog.ts`: в каталог перенесена ценовая группа Lamarty (`tier`:
  КЛАССИКА 34 / ПРЕМИУМ 77 / ЛЮКС 22 декора) из `web/assets/catalog-lamarty.js`.
- `src/pricing.ts`:
  - `decorPrice(name)`: явная цена Победы/СФЗ для 15 ходовых декоров, иначе цена по группе
    прайса Lamarty 01.01.2026 (16 мм: Классика 2690/2980/3330, Премиум 2900/3440/3780,
    Люкс 3160/3840/4060 по колонкам тиснений; суффикс `D*` в имени → третья колонка). Источник
    цены пишется в строку сметы.
  - Скрытые направляющие: закупка цеха DTC (push) / Unihopper (с доводчиком) вместо GTV 0FPO,
    цена которого не найдена. 300 мм — по счёту ФАМ (DTC F10D300H, 1040 ₽); 350–500 — оценка по
    классу 1000–1250 с пометкой «подтвердить счётом»; 250/270/550/600 остаются без цены.
    Геометрия ящика по карте GTV 0FPO не менялась.
  - Шариковые 300 и 400 мм — интерполяция между соседними длинами прайса ФАМ, помечено.
  - Петля: SOLID PRO с доводчиком 157 ₽ (счёт Мега-Трейд 6219) вместо SOLID PLUS 115 без
    доводчика — по СТП при фасадах с ручками ставится доводчик.
  - Новая строка «Крепёж и мелочёвка корпуса» 300 ₽ на корпус (норматив старого калькулятора:
    конфирматы, полкодержатели, подпятники, заглушки). Раньше крепёж не учитывался вовсе.
- `src/hardware.ts`: подписи систем направляющих отражают закупку цеха.
- `src/App.tsx`, `style.css`: в выборе декора показываются группа и цена листа.
- Тесты: `tests/pricing.test.ts` (5 новых), два старых теста переведены на длину 550 мм, у
  которой цены по-прежнему нет. Всего 126, все проходят. Сборка проходит.
