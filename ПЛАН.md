# Конструктор шкафов — план и декомпозиция

## Статус после второй ночи (03.09)

Сделано по фидбэку Max: фальш = панель 16 мм только в зоне выкатного элемента; ящики секциями (count × высота, редактируются); цоколь 80 с правкой из тулбара и кликом; клик по жёлтому размеру = инлайн-ввод; виды Спереди/Сбоку/Сверху; глубина у каждого модуля своя; новый рендер (текстуры с объёмом, тени, хром-штанга с плечиками, дощатый пол); зум колесом + пан ПКМ + двойной клик сброс; Ctrl+Z; Delete; шаблоны модулей (платяной/с ящиками/полочный); дублирование модуля; гильотинный раскрой с картами листов и КИМ; цена закупка × наценка (наценка в свойствах проекта); КП одной кнопкой (окно печати или скачивание HTML); библиотека проектов; демо «Прихожая» в библиотеке; живой чертёж на лендинге.

Не сделано (очередь): перегородки в модуле, угловые модули (вид сверху уже готов под них), редактор купе, точный нестинг под ЧПУ, сборочные чертежи, УП и отправка на почту цеха.


*Ночная смена 01.09.2026. Решения Max из интервью: пользователь — менеджер (архитектура под будущий клиентский режим), скоуп ночи — распашные в глубину, Лемана — парсинг с сайта, цена — закупка × наценка (закладывается в модель, к утру не обязательна).*

## Видение (из ТЗ Max)

Между Базисом и калькулятором дверей купе: менеджер задаёт помещение и глубину, дальше «играет в тетрис» модулями, всё само проставляет размеры, петли, фальши и собирает спецификацию. Поздние этапы: карты раскроя, сборочные чертежи, смета, отправка на производство с УП.

## Декомпозиция (ночь = этапы 1-6, дальше следующие сессии)

1. **Данные**: константы конструктива цеха (vault), каталог Lamarty 133 декора + 129 текстур (готово, скопированы из Calc), фурнитура с вычетами, ручки и сетчатые системы Лемана Про (парсинг).
2. **Модель**: помещение → композиция → модули (нижний/верхний, ≤1200×≤2200) → секции → наполнение → фасады. JSON-сериализация, купе заложен как тип фасадной системы.
3. **Движок правил**: валидация вставки, автофальш при ящиках у стороны петель, автопетли по высоте, подгонка модуля под технику фурнитуры (с подтверждением), тех. зазоры от стен/потолка.
4. **Редактор (SVG)**: холст-вид спереди, палитра модулей и наполнения (drag), клик по элементу → свойства (декор с текстурой, открывание push/ручка, тип направляющих), размерные линии, переключатель «каркас/с фасадами», живая спецификация деталей и фурнитуры.
5. **Сохранение**: localStorage + экспорт/импорт JSON.
6. **Лендинг-обёртка** (минимальный) + десктоп-версия «Просчитано» с кухнями на фоне.

## Конструктивные допущения (согласовать утром!)

Все значения вынесены в `data/constants.js` — правятся без кода:
- Фальш при выкатных ящиках за распашным фасадом: по стороне петель, ширина по умолчанию 60 мм.
- Петли по высоте фасада: до 900 — 2 шт, до 1600 — 3, до 2000 — 4, выше — 5.
- Подгонка под сетчатую фурнитуру: конструктор ПРЕДЛАГАЕТ расширить модуль до требуемой ширины, менеджер подтверждает.
- Модуль ночной версии = одна секция (перегородки в v2), жёсткая полка не ограничена, съёмная с предупреждением о провисании при пролёте > 800.
- Точные значения из vault (цоколь, царги, вычеты направляющих, зазоры) подставляются по ходу ночи, чего нет в файлах — типовые с пометкой TODO.
