    Вид сзади. Координаты от верхнего левого угла.

    Выберите чашку на чертеже или перетащите её по высоте. Монтажные отверстия, крепёж и столкновения с корпусом требуют проверки технологом.

    Стоимость выбранного фасада

    Клиентские ставки. Пустое поле - цена не задана; 0 - операция включена.

    Для МДФ в плёнке действует прайс Конструктора. Ручная ставка полотна заменяет автоматическую.

    Толщина всех фасадов

    Изменятся все позиции. При несовместимости с выбранным рисунком или материалом операция будет остановлена целиком. Ставки полотна нужно подтвердить заново.

    Цвет алюминиевой рамки

    У прежнего каталога нет перечня цветов этих профилей. Укажите согласованный цвет вручную.

    Распределить петли

    Промежуточные центры распределяются равномерно. Количество и параметры петли подтвердите по технической карте.
