# Состояние сессии — обновление 05.09.2026

## Новый приоритет и 3D-редактор

Макс разрешил менять архитектуру ради качества. Цель: собственный понятный редактор для менеджеров, затем раскрой, чертежи, УП и бирки — замена Базиса в процессах цеха. Цены вторичны. Сейчас выполняется только этап 1: 3D-редактор одного модуля.

Исходники новой версии: `studio/` (React, TypeScript, Three.js). Сборка: `web/studio/`. Запуск: `START-3D.bat`, адрес http://127.0.0.1:8103/studio/ . Подробности и ограничения: `studio/README.md`. Старый 2D-редактор и SQLite сохранены.

Реализовано: корпус с габаритами, до 4 секций с регулируемой шириной, полки по высоте, ящики, штанга, фасады, каталог, виды, undo/redo, локальное сохранение и JSON. Геометрия модели и список деталей используют одно ядро. Проверки не допускают некорректное изменение; это ещё не производственный выпуск.
