# Конструктор шкафов

2D-конструктор распашных шкафов и гардеробных «между Базисом и калькулятором купе»: менеджер задаёт помещение и глубину, собирает шкаф из модулей как тетрис, конструктор сам проставляет петли, фальши и тех. зазоры и ведёт живую спецификацию.

**Запуск:** двойной клик по `ЗАПУСК.bat` → откроется http://localhost:8102. Лендинг на главной, редактор в `editor.html`. Это чистый клиент, интернет не нужен (кроме шрифтов).

## Что умеет сейчас

- Нижние (на цоколе 100) и верхние модули, лимиты 250-1200 × 300-2200, перестановка перетаскиванием.
- Наполнение drag&drop: полки съёмные/жёсткие, штанги, ящики (шариковые / скрытые DTC-Unihopper / метабоксы), сетчатые элементы Лемана.
- Правила: ящик за распашным фасадом → автофальш по стороне петель; сетка не лезет → предложение расширить модуль до технички; секция шире технички → фальш; штанге мало высоты → отказ; пересечения и провисание полок → предупреждения.
- Фасады: 1/2 двери, петли GTV по стандарту цеха (до 1200 две, выше три), push или ручка из каталога Лемана, декор корпуса и фасадов кликом из 133 текстур Lamarty.
- Живая спецификация: детали с размерами и кромкой (2 мм лицевые, 0,4 техническая), фурнитура с закупочными ценами, площадь ЛДСП.
- Сохранение в браузере + экспорт/импорт JSON.
